# Memories

This directory contains the context and history that Hermes has built up about Gabriel and his environment. It allows Hermes to retain context across sessions and restarts.

## Files

*   **`USER.md`:** This is the core profile of Gabriel. It contains his background, preferences, communication style, and specific directives for how Hermes must interact with him (e.g., blunt execution, no apologies, focus on high-ticket revenue).
*   **`MEMORY.md`:** This file contains important historical context, ongoing situations, and specific facts Hermes needs to remember (e.g., medical urgencies, the 7 core products, preferred tools, and specific environment quirks like the macOS python3 path).

*Note: These files are updated by Hermes as he learns new information that needs to be permanently stored.*
