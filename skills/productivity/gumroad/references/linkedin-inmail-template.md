## Key Principles

1. **All 7 products listed** — Gabriel doesn't want to send individual links. Let the buyer choose.
2. **"Life happens" is OK** — acknowledges reality without dumping the load on the buyer.
3. **NO specific medical/financial details** — "$200/week meds for my son" is too heavy for a product pitch.
4. **Personalization** — only the first line `{name}` changes per recipient.
5. **Clear value math** — $1.58/prompt → $1,584 total → now $7-$29.
6. **No follow-up needed** — all links are in the message.
